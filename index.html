O que cada arquivo faz

HTML, CSS e JavaScript

Cada tecnologia cuida de uma parte. Os trechos abaixo vêm desta própria página.

Estrutura

HTML

Define o que existe na página: títulos, textos, botões e campos.

<button id="tema">
  Tema escuro
</button>

Aparência

CSS

Define cores, fontes e espaços. As cores ficam em variáveis, o que permite trocar de tema.

:root {
  --accent: #2b46f0;
}
.btn.primary {
  background: var(--accent);
}

Comportamento

JavaScript

Reage a cliques e digitação: adiciona tarefas, valida o formulário e atualiza o relógio.

botao.addEventListener(
  "click",
  alternarTema
);
